# 原始记录索引

## 1. 串口/分析仪证据（`logs/`）

每次采集一个目录：`logs/<时间戳>_<tag>/`，内含 `boot.txt`（本次启动的串口）、`console.txt`、
`decoded.txt`（分析仪解码）、`meta.txt`。梗概见 [../logs/README.md](../../logs/README.md)。
