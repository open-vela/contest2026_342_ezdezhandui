## 四、已定位但未打通的测试（🔶，根因明确）

### 7.3 本轮暴露的新问题（供下一轮）

1. **`/dev/fb0` 缺失**：`EK79007 DCS 0xb2` 超时（-110，I2C0 无应答）。
   摄像头 SC2336 在同一 I2C0 上正常应答 → 说明 I2C 控制器本身可用，
   问题在 **LCD 模组本体/供电/FPC**（代码已提示 `J1->J6 jumper required`）。
2. **DNS 缺省不可用**：无 `/etc/resolv.conf`。建议把 DNS 配置纳入板级 bringup
   （或 defconfig 走 DHCP），否则 ai_agent 的 LLM HTTPS 通路在域名解析这步就断。
3. **ai_agent 的 `vela>` CLI 仍不可交互**：agent 启动后 console 输入无响应
   （NSH 在 agent 启动前完全正常）—— 需要把 agent CLI 的 stdin 处理与
   NSH 的 console 复用问题单独排。
