# 评审复现手册

## 1. 环境

- openvela 工作区（`repo sync` 后），本队 manifest 已部署（`contest2026_342_ezdezhandui.xml`）；
- 工具链：`prebuilts/gcc/linux-x86_64/riscv-none-elf`（仓内自带）；
- 板子：ESP32-P4X-C5 Function-EV-Board（板载 C6 跑 esp-hosted 从机固件）。

## 2. 构建与烧写

```bash
cd <workspace>
./build.sh vendor/espressif/boards/esp32p4/esp32p4-function-ev-board/configs/nsh --cmake -j8
cd contest2026_342_ezdezhandui && bash tools/build_flash/usb_stable.sh
```

## 3. 真机验收（三项）

```bash
cd contest2026_342_ezdezhandui
python3 tools/test/evidence.py --reset --seconds 400 --analyzer 400 --decode --tag review
grep -a "connected to\|DhcpDnsStatus.*dhcp=1\|wlan0 address" logs/*review*/boot.txt
```

期望：
- `connected to "<你的 AP>" ... rssi=… ch=…`
- `DhcpDnsStatus iface=0 link=1 dhcp=1 ip=192.168.1.9`
- `wlan0 address 192.168.1.9 mask 255.255.255.0 gw 192.168.1.1`

> 连接用的凭据放在 `~/.wifi_test_creds.cmake`（不进仓），见
> [../30_实现/连接_WiFi_SDIO.md](../30_实现/连接_WiFi_SDIO.md) 附录 BY.20。

## 4. 一致性自查

```bash
python3 tools/engineering/check_consistency.py
python3 tools/engineering/gen_manifest_copyfiles.py --check
```
