## 维护约定

1. **归类判据**：讲流程/规划/状态/测试 → `01_开发流程`；讲某条驱动或外设怎么实现 → `02_驱动实现`；一次故障的现象→根因→修法 → `03_踩坑笔记`；会被正文直接引用的证据文件 → `04_证据`；讲上游平台本身 → `00_总览`。
2. **命名**：文件名语义化，**不再带旧编号前缀**；踩坑笔记保持 `NN_主题.md` 的时间序。
3. **引用**：跨目录一律写全路径，如 `docs/01_开发流程/STATUS.md`；同目录内用相对路径 `xx.md`。
4. **同步**：每个目录新增文件时，同步更新该目录 README 的表格；状态类结论只写在 `STATUS.md` 一处。
