# 原始记录索引

## 1. 串口/分析仪证据（`logs/`）

每次采集一个目录：`logs/<时间戳>_<tag>/`，内含 `boot.txt`（本次启动的串口）、`console.txt`、
`decoded.txt`（分析仪解码）、`meta.txt`。梗概见 [../logs/README.md](../../logs/README.md)。

| 目录 | 内容 |
|---|---|
| `logs/20261102-124236_espressif-move/` | **2026-11-02 通用层零写入搬迁后的 clean-room 复验**：全新构建目录 configure+build、两镜像烧录、真机三项（MCUboot v2.4.0-151 / NSH / connected rssi=-46 ch=6 / DhcpDnsStatus ip=192.168.1.9 / wlan0 192.168.1.9）。同目录 `irq_guard_regression.txt` 记录 NSH `exit` 回归（守卫下沉后未复现"任务退出→整机失聪"）。无分析仪波形（未插 Saleae） |
| `logs/20261102-090754_cleanroom/` | 迁移前一轮 clean-room（含分析仪解码） |
| `logs/20261101-211034_shared-minimal/` | 共享层最小交付集实验 |
