# 03_踩坑笔记 —— 按时间顺序的 7 篇单点故障记录

> 修 bug、复现某个现象、或想知道「这个结论是怎么得出的」时进来查。
> 每篇都是「结论先行 + 根因 + 复现命令」；**读 03 篇前请先读 04 篇**（03 的历史前提已失效）。
> 本目录说明与索引编制于 2026-10-31（各文件最后更新以文件内标注为准）。

## 本目录做什么

放**单点故障的排查过程与根因**，按时间推进排列（#01 最早）。**不放**项目流程与规划（`docs/01_开发流程/`）、
不放当前状态口径（`docs/01_开发流程/STATUS.md`）、不放驱动交付说明（`docs/02_驱动实现/`）。
本目录是「经验库」：现象 → 根因 → 修法，写的是当时的判断，**不等于当前配置**。

## 维护约定

- 新增文档若记录**一次故障的现象→根因→修法**，归本目录；成体系的测试与结果归 `docs/01_开发流程/功能闭环测试.md`。
- 文件名保持 `NN_主题.md` 的**时间序**编号；旧 `踩坑笔记_0X_*.md` 的对照见 `docs/README.md`。
- 前提会失效的篇章必须在开头写明「本篇写于××时代、其××已失效」，并指向取代它的那一篇。
- 跨目录引用一律写全路径，如 `docs/01_开发流程/STATUS.md`；本目录新增文件时同步更新本文件表格。
