# 提交清单与产物

## 作品仓（提交主体）

- `nuttx/**` — 内核/arch/驱动改动（P4 自有代码集中在 `arch/risc-v/src/esp32p4/`）
- `board/esp32p4/**` — 板级源码与 defconfig
- `app/apps/**` — 应用（camera 示例、lvgl 端口、netinit、mbedtls 等）
- `app/ai_agent/**` — ai_agent 模块
- `docs/**` — 本套文档（8 大类）
- `tools/**` — 采集/验证/导出工具

## 产物

| 产物 | 位置 |
|---|---|
| 固件镜像 | 构建后 `cmake_out/<board>_<config>/nuttx.bin`（不入仓） |
| 真机证据 | `logs/<时间戳>_<tag>/`（boot/console/decoded/meta） |
| 截图 | `docs/40_验证与证据/截图与对照日志/` |
| 提交材料 | 仓根 `提交材料/`（视频、作品介绍 docx/pdf、运行日志） |

## 核验

```bash
python3 tools/engineering/check_consistency.py     # 工作区 ↔ 作品仓 双向对账（应 ✅）
python3 tools/engineering/gen_manifest_copyfiles.py --check   # manifest 与文件树一一对应
```
