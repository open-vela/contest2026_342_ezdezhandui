# 04_证据 —— 可随文档引用的真机截图与对照日志

> 想核验「真机真的跑出来了吗」的人看这里。这里只放**少量高价值文件**（两张），
> 更多真机证据（原始日志、帧缓冲 PNG、摄像头实测）在仓库 `logs/verify-2026-09-17/` 与 `提交材料/`。
> 本目录说明与索引编制于 2026-10-31（各文件时间以文件系统为准）。

## 本目录做什么

放**证据文件本体**：真机帧缓冲导出截图与原厂固件对照日志，供文档直接引用与评审抽查。
**不放**证据的文字说明（那在 `docs/40_验证与证据/测试体系与方法.md` 与各驱动文档里）、
不放采集脚本（那在 `tools/test/`）、不放大批量原始日志（那在 `logs/verify-2026-09-17/`）。
本目录保持「小而稳」：文件一旦被文档引用就不要改名，改名需同步所有引用处。

## 维护约定

- 新增证据文件归本目录的判据是：**体积可控、会被文档正文直接引用**；大批量原始日志放 `logs/`，不要搬进来。
- 文件名语义化并注明来源口径（本作品固件 / 原厂对照），不要只写 `log.txt` 这类无信息名。
- 引用图片用相对路径，如 `![LVGL 界面截图](截图与对照日志/验证截图_LVGL界面_1024x600.png)`；跨目录引用写全路径。
- 本目录新增或改名文件时，同步更新本文件表格，并同步 `docs/40_验证与证据/测试体系与方法.md` 等引用处。

## 应用层（DeskMate 中控 UI）模拟器快照

`应用层_模拟器快照/` 由 `tools/test/sim_deskmate.sh` 一次运行产出（判定 `RESULT: PASS`，
自检 `DM-SELFTEST RESULT: PASS (16/16)`）：

| 文件 | 内容 |
|---|---|
| `dm_home.png` / `dm_net.png` / `dm_camera.png` | 三个页面各一张 1024×600 截图（RGB565 原始帧 → PNG） |
| `dm_*.bin.txt` | 快照几何（width/height/bpp/stride/backend） |
| `console.log` | guest 控制台全文（含逐条 `[dm-check] … PASS`） |
| `fb2png.log` | 色数 / 主色占比 / 梯度统计（与真机同一判据：UI 梯度 <8） |
| `result.txt` | 该次运行的判定摘要（ready / checks / result / artifact_dir） |

这些快照由应用自己的 `dm_display_snapshot()` 写出：模拟器用内存显示后端，
真机用 `/dev/fb0`（配 JTAG dump）——**同一条证据链**。
